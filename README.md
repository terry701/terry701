## 5. 我做過的作品 Projects

### 📅 Project 1｜國中排課系統

使用 Python 與 Google OR-Tools CP-SAT 開發排課系統。

專案嘗試處理教師、班級、課程、固定時段與其他排課限制，
並透過測試與驗證來提升排課結果的可靠性。

**學到的內容：**
- 約束最佳化
- 排程問題
- 資料輸入與驗證
- 軟體測試
- Git 版本管理

---

### 📊 Project 2｜Angry Birds 2 財富塔資料研究

以遊戲中的「財富塔」機制為研究情境，
建立可追溯、可驗證的資料蒐集與分析流程。

研究重點不是預先假設存在規律，
而是透過資料蒐集、清理、探索性分析與統計方法，
判斷結果是否真的存在可被資料支持的規律。

**學到的內容：**
- 資料蒐集與清理
- 研究設計
- 統計分析
- 資料驗證
- 可重現研究流程

---

### 📄 Project 3｜公文路由系統

嘗試建立公文分類與路由系統，
將不同類型的公文依照規則分派到適合的處理單位。

除了分類功能，也建立測試、資料規格與稽核流程，
讓系統的判斷結果可以被檢查與追蹤。

**學到的內容：**
- 資料分類
- 軟體驗證
- 測試設計
- 資料規格
- 系統流程設計
